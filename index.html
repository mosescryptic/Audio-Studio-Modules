04 / Production markers

AUDIO-SIDE HANDOFF

Markers are anchored to script sections/word positions, not audio time. Word markers save the anchored token and nearby context; if text edits invalidate that anchor, the marker is flagged stale for review. Section reordering preserves section IDs.

Word / phrase replacement requests

PLANNED AUDIO WORKFLOW

Click the first word, then Shift-click the last word to select a short phrase in the same section. Mark it for re-recording. This saves the exact text range and surrounding context; it does not record or blend audio in this prototype.

Prototype only: no microphone or recording is connected. Transcript alignment, recording, waveform edits, crossfades and audio blending are not implemented here.
